- ユーザー提示の実ファイル `★英語学習ゲーム_001_追記済み009.xlsx` はこの環境に添付ファイルとして存在しなかったため、実ファイルアップロードのブラウザ確認は未実施です。

- 複数シートExcelは、指定3シートがすべて存在する場合のみ3モードブックとして扱います。一部だけ存在するExcelは既存互換のため先頭シート単一読み込みとして扱います。
