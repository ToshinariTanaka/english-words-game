## 今回やったこと
- study-app の学習画面で、問題ID・レベル・学習履歴を表示する情報ブロックを、問題本文・選択肢・判定フィードバックの近くから「次の問題へ」ボタン直下へ移動しました。
- 正解・不正解の判定後も「次の問題へ」ボタンの下に同じ情報が続けて表示されるよう、判定メッセージ用の `feedback` と問題情報用の `questionMeta` を分離しました。
- 表示内容・計算ロジック・文言は変更せず、位置だけを変更しました。
- スマホ表示でもボタン下に自然に並ぶよう、既存のフィードバック見た目を踏襲しつつ下余白を抑えた専用スタイルを追加しました。

## 注意点
- `questionMeta` は問題表示中のみ表示し、読み込み中・空状態・結果画面では非表示にしています。
- 判定後の正解・不正解メッセージは従来どおり選択肢下の `feedback` に表示され、問題ID・レベル・学習履歴だけがボタン直下に表示されます。
- スクリーンショット未取得のため、実機またはブラウザで最終見た目を確認するとより安心です。
