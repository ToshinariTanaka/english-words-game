## 今回やったこと
- study-app の手動音声選択、ランダム選択、自動選択を、指定された10種類の音声だけに限定しました。
- `voice.name` と `voice.lang` の大文字小文字を区別しない一致判定で、ブラウザから取得できた許可音声だけを指定順に表示するようにしました。
- 許可音声が0件の場合は固定音声候補を出さず、読み上げ時も `utterance.voice` を指定しないことでブラウザ既定音声へフォールバックする仕様をテストで固定しました。
- 許可候補外、または現在のブラウザで取得できない保存済み音声は、自動選択へ戻して保存値をクリアするようにしました。
- 音声選択欄の説明文、README、設計ドキュメント、プロジェクト状況を更新しました。

## 注意点
- ユーザー指定に合わせて `Moria / en-IE` のみを許可しています。実機で `Moira / en-IE` として取得される場合は、後続対応で許可リストへ追加してください。
- ブラウザやOSによって指定10種類の音声が存在しない場合があります。その場合、存在しない音声は候補に表示されません。
- UI文言変更のみでレイアウト構造は変更していません。スクリーンショット取得はローカル確認環境の都合で実施できていません。
