## 注意点
- Web Speech APIの音声一覧と `voiceURI` はOS・ブラウザ・端末に依存します。PCとiPhone/Safariで実際の音声候補数や音声名が異なる可能性があります。
- iPhone/Safariでは初回表示時に音声一覧が空になることがあります。その場合でも「ランダム」は保存値として維持し、`voiceschanged` 後に候補を再表示します。
- 自動選択で `utterance.voice` を指定しない場合、実際にどの音声が選ばれたかはブラウザ側の挙動になるため、表示は「ブラウザ自動選択」としています。
- スクリーンショットは環境にブラウザがないため未取得です。UI変更内容は、音声選択プルダウンの「ランダム」追加と、読み上げボタン付近の音声ステータス追加です。
