## 今回やったこと
- `study-app/` の出題数初期値を10問に固定し、過去に保存された `all` や不正値は初期化時に10問へフォールバックするようにしました。
- 10問選択時は実際の出題数・進捗・説明文が10問基準になるようにし、「全て」を選んだ場合だけ全問出題の表示になるよう補強しました。
- 自動読み上げ付近に音声選択プルダウンを追加し、Web Speech API の音声一覧から英語系音声を優先表示するようにしました。
- 選択した音声を `localStorage` に保存し、次回起動時や `speechSynthesis.onvoiceschanged` 発火後に復元できるようにしました。
- 英単語モード・チャンクモードの出題カードにモード別クラスを付与し、問題文・選択肢・進捗行・もう一度聞くボタンを少し大きくしました。英文和訳モードには拡大スタイルを適用していません。
- UI変更のためスクリーンショット取得を試みましたが、この実行環境にはブラウザ/Playwrightがなく取得できませんでした。

## 注意点
- 音声一覧はブラウザ・OS・端末に依存します。iPhone/Safariでは取得できる音声が少ない、または初回表示直後は「自動選択」のみになる場合がありますが、`voiceschanged` 後に再読み込みされます。
- 音声の変更による実際の声質差はブラウザ実機での手動確認が必要です。
- 出題可能数が10問未満の場合、10問設定でも実際には読み込めた問題数までの出題になります。
- スクリーンショットは環境にブラウザがないため未取得です。UI変更内容は、音声選択プルダウン追加と英単語/チャンク出題カードの文字拡大です。
