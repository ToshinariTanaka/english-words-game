## 今回やったこと
- study-app の Web Speech API 音声候補から、歌声・歌唱系キーワードを含む音声を除外するフィルタを追加しました。
- 音声選択プルダウン、ランダム音声候補、固定音声の解決処理がすべて同じフィルタ済み候補を使うようにしました。
- 自動選択時もフィルタ済み候補がある場合は通常ナレーション候補を明示的に使い、候補がすべて除外された場合だけ Web Speech API の既定自動音声に任せるようにしました。
- 保存済みの固定音声が除外対象になった場合、自動選択へフォールバックして保存値もクリアするようにしました。
- 歌声系キーワード除外、通常英語音声の維持、保存済み除外音声の自動選択フォールバックを検証するテストを追加しました。

## 変更ファイル
- `study-app/script.js`: 歌声・歌唱系音声の除外キーワード、フィルタ関数、表示・ランダム・固定・自動選択の候補制御を追加。
- `tests_study_app_voice_filter.js`: 音声フィルタと保存済み除外音声フォールバックのテストを追加。
- `package.json`: `npm test` に音声フィルタテストを追加。
- `docs/codex_report.md`: 今回の作業内容へ更新。
- `docs/project_status.md`: study-app 音声選択の歌声除外対応状況を追記。

## 注意点
- 実ブラウザにインストールされている実音声一覧は環境依存のため、この環境では実機のプルダウン表示や再生音までは確認していません。
- フィルタ済み候補がすべて除外された場合は、アプリを壊さないため `utterance.voice` を設定せず、Web Speech API の通常自動選択にフォールバックします。
- UIレイアウトの変更はなく、音声候補の中身だけを変える修正です。スクリーンショットは取得していません。
