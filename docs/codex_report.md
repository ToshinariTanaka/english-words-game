## 今回やったこと
- study-app の手動音声再生ボタンを、問題文直下から上部のモード表示右側へ移動しました。
- 手動音声再生ボタンの画面表示文言「もう一度聞く」を削除し、スピーカーアイコンのみを表示するようにしました。
- アクセシビリティ向けに、音声再生ボタンの `aria-label` と `title` には「音声を再生」を残しました。
- 音声ステータス表示を、問題文直下ではなく「問題ID・レベル・学習履歴」の下へ移動しました。
- スマホ表示でもモード名・スピーカー・進捗が横並びで崩れにくいよう、上部行とスピーカーボタンのCSSを調整しました。
- 既存のMP3優先再生、Web Speech APIフォールバック、自動読上げON/OFF、音声選択ロジックは変更していません。
- README、設計メモ、プロジェクト状況を今回のUI変更に合わせて更新しました。

- 画面上のボタン文言はスピーカーアイコンのみですが、スクリーンリーダーやホバー説明向けの `aria-label` / `title` は維持しています。
