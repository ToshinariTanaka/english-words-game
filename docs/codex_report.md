## 今回やったこと
- study-app の全問終了画面に「問題設定へ戻る」ボタンを追加しました。
- ボタン押下時に `#settingsTitle`（出題設定見出し）へスムーズスクロールする処理を追加しました。
- 出題開始時・出題途中・空状態・読み込み中は戻るボタンを非表示にし、全問終了後だけ表示されるようにしました。
- 復習モードの終了時にも同じ戻るボタンが表示されるようにしました。
- スマホでも押しやすいよう、既存の `secondary-button` を再利用しつつ戻るボタンの最小高さを確保しました。
- 戻るボタンの存在、初期非表示、スムーズスクロール処理、押しやすいサイズ指定を自動テストに追加しました。
