## 今回やったこと
- study-app のセッション終了後の結果画面に、今日・今月・今年・累計の勉強数を表示する統計欄を追加しました。
- 勉強数を「解答した問題数」として、正解・不正解に関係なく1問の初回解答時だけ `localStorage` の専用キー `englishWordsGame.studyApp.studyCounts.v1` に保存するようにしました。
- 日付はブラウザのローカル日付 `YYYY-MM-DD` で保存し、表示時は `byDate` から今日・今月・今年を再集計するようにしました。
- 既存の学習履歴 `englishGameLearningStats` には手を入れず、クリア処理の対象にも含めない方針を維持しました。
- 勉強数カウンター用の回帰テストを追加し、`npm test` に組み込みました。

## 変更ファイル
- `study-app/index.html`: 結果画面用の勉強数カウンター表示欄を追加。
- `study-app/script.js`: 勉強数の読み込み・保存・日付集計・結果画面描画・初回解答時加算を追加。
- `study-app/style.css`: スマホでも見やすいカード形式の勉強数カウンターCSSを追加。
- `tests_study_app_study_counts.js`: 勉強数の加算、二重加算防止、localStorage復元、結果表示のテストを追加。
- `package.json`: `npm test` に勉強数カウンターのテストを追加。
- `docs/project_status.md`: 今回の実装状況を追記。
- `docs/codex_report.md`: 作業内容を本内容に更新。

## 注意点
- UI変更がありますが、この実行環境にはブラウザ操作用のスクリーンショット取得手段がないため、実機スクリーンショットは未取得です。表示は結果メッセージ直下にカード形式で追加しています。
- 勉強数カウンターは既存学習履歴とは別キーで保存します。既存の「学習履歴をクリア」では削除されません。
- 不正なJSONなど保存データが壊れている場合は、空データとして扱いますが、アプリ起動時に空データで上書きはしません。
