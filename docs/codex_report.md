## 今回やったこと
- study-app の手動音声選択プルダウンを、特殊音声を含む Web Speech API 取得音声の全候補表示へ変更しました。
- 手動プルダウンの最大10件制限を廃止し、`en-US`、`en-GB`、`en-AU`、`en-CA`、その他 `en-*`、その他言語の順に整理して表示するようにしました。
- ランダム選択・自動選択は従来どおり、`good news` / `bubbles` / 歌声・特殊効果系を除外したおすすめ候補を使うよう分離しました。
- ユーザーが `good news` や `bubbles` を明示選択した場合は、固定音声としてそのまま保存・復元・再生対象にできるようにしました。
- 音声選択欄に候補数（例: `音声候補：132件`）と説明文を追加しました。
- 20件以上・100件以上の音声候補、特殊音声の固定選択、ランダム/自動候補の特殊音声除外、保存済み固定音声復元のテストを追加・更新しました。

## 注意点
- Web Speech API の実際の音声数は OS・ブラウザ・インストール済み音声に依存します。この環境ではユニットテストで 130 件のモック音声を使い、100件以上表示できることを確認しています。
- UI変更がありますが、この実行環境ではブラウザ表示用スクリーンショット取得手段がないため、実画面スクリーンショットは未取得です。変更内容としては音声選択欄の下に候補数と説明文が追加されます。
- ランダム/自動選択は引き続き最大10件のおすすめ候補から選びます。これは特殊音声を勝手に選ばないための安全策です。
