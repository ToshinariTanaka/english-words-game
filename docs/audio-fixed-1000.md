# 追加1,000本の固定生成

対象は既存の試作60本・追加試作20本を除いた、問題キー順の英単語500問×Nova/Ashです。
対象リスト全体のSHA-256をコードに固定し、再実行しても次の1,000本には進みません。
モデル・発音指示・音量処理は試聴済みの設定を維持します。

## 実行

1. PRの無料テスト成功後にmainへマージ。
2. Actions → **Generate fixed 1000 audio files** → Run workflow → main。
3. 有料生成のチェックを入れて1回実行。
4. 500本の内部区切りを自動で進め、同時に最大2本だけ処理。
5. 成功時のartifact **nova-ash-fixed-1000** を展開し、listen.htmlで試聴。

チェックなし・push・pull_requestはオフライン検証だけです。PR作成やマージでは生成しません。
新規API呼び出しは固定対象1,000本までです。金額のハード上限ではありません。
料金はOpenAI Usageをup-words-audioに絞って確認します。短い20本の表示額<$0.01を全教材へ単純換算しません。
GitHub Actionsの実行時間は別途、そのリポジトリの利用枠・課金設定に従います。

## 保存と停止

- 既存80本を検証し、対象1,000本の不明なリクエストがないか全件確認してから生成。
- MP3・元音声・完了記録は既存方式でR2へ1本ずつ条件付き保存。上書きしません。
- 最初のエラーで待機中の処理を止めます。もう一方ですでに処理中の最大1本は完了まで動く場合があります。
- タイムアウト・429などの自動再送はしません。request.jsonがあって元音声がない場合は、不明な課金結果として全体を停止します。
- 元音声保存済みならAPIを呼ばずに音量処理から再開。完了済みは検証してスキップ。
- 開始から150分以降は次のファイルを開始しません。workflow全体は180分まで。
- 再実行は同じworkflowを使用。結果不明の停止は、記録を削除せず調査してください。
- 通常のエラー時も進捗・ローカル救済音声をartifactへ保存します。強制終了ではartifact保存が保証されないため、R2の記録を正とします。
- 全1,000本を再走査し、有料APIを拒否する処理で再利用1,000本・追加呼び出し0件を確認します。

アプリの公開マニフェストは変更しません。公開切替と全残件の生成は別工程です。
初回完了で既存80本と合わせて1,080本、全18,370本に対する残りは17,290本になります。
