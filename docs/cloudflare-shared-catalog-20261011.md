# Cloudflare共通教材と旧Render廃止の確定方針

2026-10-11、田中塾長の指示を反映。共通教材の方針と実装状況を記録する。本番の教材切替は未実施。

## 旧Render

- 英単語ゲームは通常版・中学生版ともに廃止対象。旧教材・旧音声・旧学習記録の引継ぎとバックアップは不要。
- 旧Renderデータの保全を停止の前提にしない。旧音声はNova・Ashの生成には利用しない。
- 対象サービスは `english-words-game`、`english-words-game-junior`、旧試験用 `english-words-game-pr102`、一時移行試験用 `up-junior-static-preview-20261008`。
- `english-words-game-pr102-db-recovery` も英単語専用DBの廃止対象。実際の削除操作では他アプリから利用されていないことを確認する。
- 授業報告、連絡アプリ、それらの開発環境・バックアップ、歴史クイズは対象外。
- CloudflareのD1・R2、GitHubリポジトリ、今回用意した生成ツール・音声仕様は継続使用する。
- 最初に英単語Webサービスを一時停止し、Cloudflareの動作を確認する。永久削除は停止と別に結果を記録する。

## 共通教材の構成

- Cloudflareを大人・高校生・中学生などに共通の英語学習基盤とする。
- 全4モード・9,185問を共通の正本として保持する。全年齢分と中学生分の問題本文を二重管理しない。
- 中学生向けは共通教材から出題範囲を選ぶ。例はCEFR A1〜A2。教材フラグでも対象を選べる構成にする。
- A1/A2は現在のB列 `level` で判定できる。N列 `target1800` のような教材フラグは別の属性として保持し、レベルと混同しない。
- 「A1〜A2」はA1またはA2の意味。どの教材フラグを中学生向けの標準条件にするかは、ユーザーが例示した段階なので固定しない。
- 出題条件を変更しても全問の正本は削除・置換しない。モード・レベル・教材条件に合う問題だけを学習セッションに渡す。
- 全問の正本を公開する際は各モードの件数・キー・フラグを検査し、現在の教材版から明示的に切り替える。

## 共通教材の実装（本番未反映）

- 管理画面は「全問題（全年齢共通）」で取り込み、公開する。過去の絞り込み済み教材との互換性のため、APIと変換関数は旧フィルタ値も読み込める。
- 生徒画面に「中学生向け：A1〜A2」「全レベル：A1〜C2」の選択ボタンを追加。どちらも教材条件を「すべての教材」に戻す。
- 教材条件「中学ターゲット1800」は英単語で `target1800=1`、他3モードでA1/A2を選ぶ。さらに選択中のレベル範囲とのAND条件で出題する。標準条件への固定はしない。
- N列 `target1800` は任意。見出しがあれば全問公開でも各行に0/1を保持する。見出し位置の誤り・不明な値は検査エラーにする。フラグを持たない従来データも読み込める。
- 条件変更で対象が0問になったときは、前の問題・選択肢・復習対象・音声を解除し、出題を止める。教材全体は保持する。
- 教材条件はページを開くたびに「すべての教材」。レベル範囲は従来どおり端末内に保存する。生徒属性に応じた自動割当や端末間同期は今回の対象外。
- 表示名を「Up英語トレーニング」に変更。内部名 `junior`、URL、問題キー、学習記録用D1スキーマは維持する。共通のRender用ソースは変更せず、Cloudflareビルドに機能を追加する。

## 実教材の検査と公開手順

- 添付 `☆英語学習ゲーム__英単語_111(2).xlsx` を全問で変換・検査：英単語7,489、チャンク856、文節441、英文399、計9,185問。問題キー・レベル・選択肢の検査成功。変換データ約2.65MBで12MB制限以内。
- このExcelにN列の教材フラグはない。A1/A2選択は可能。ターゲット1800の対象は未指定なので、フラグが必要なときは元Excelの英単語シートN1に `target1800`、対象行に1を追加する。こちらで対象を推測して付けない。
- 2026-10-11に確認した公開API `/api/questions/status` は `filter: a1a2`、英単語1,652・チャンク29・文節5・英文5、計1,691問（教材更新日時2026-10-09T03:16:12.578Z）。コードの更新だけではこの公開教材は9,185問にならない。
- 本番切替には、生徒・管理画面のコード反映後、管理画面で元Excelを選び「Excelを検査する」→4モードの件数を確認→公開を行う。成功後、公開APIの `filter: all` と上記件数を確認する。既存の4モードをステージして最後に版を切り替える公開方式を使う。
- 画面でA1/A2と全レベルを切り替え、TESTPROD001の採点と学習履歴も確認する。新音声が未公開の間は端末音声を使用する。
- 全問の保持とフラグの公開往復、実画面スクリプトでの条件の組合せ・0問時の停止を自動テストで確認する。実機と本番公開確認は別に実施する。

## 音声への影響

- 生成対象は変更なし：9,185問×Nova・Ash＝18,370本。読み上げるのはC列の英語のみ。
- 同じ問題キー・英文・声に対するMP3を全年齢で共用する。中学生向けの抽出で複製・再生成しない。
- 初期音声はNova。Ash・ランダムへ切替可能。同じ問題の聞き直しではランダム選択の結果を維持する。
- 公開用音声manifestは、その時点でCloudflareに正式公開された教材キー・英文に合わせる。全問正本への切替前に音声だけで公開範囲を広げない。
- 有料生成・R2への配置は未実施。試作30問×2声で発音・音量・実費を確認してから全件へ進む。

## 引き続き確認する運用事項

Cloudflareでの通信切断後の記録復旧、本番D1の書き出しと別DBへの復元、管理者Gmailログインメールの受信は別途確認する。旧Renderのデータ引継ぎとは別の課題として扱う。
