# 固定10問・20本の生成確認

全問量産の前に、R2に直接記録する生成処理を少量で確認します。
対象は次の10語のNova/Ash計20本だけです。

aardvark / abaft / abalone / abandon / abandoned / abash / abashed / abate / abatement / abbreviate

対象の英語と問題キーを固定しています。再実行しても次の20本へは進みません。
既存の試作30問・60本は照合して再利用し、この操作で作り直しません。

## モデル・費用確認（2026-10-13）

- 試作と同じ `gpt-4o-mini-tts-2025-12-15` を使用。
- 公式モデルページの料金は入力テキスト100万トークンあたり$0.60、出力音声100万
  トークンあたり$12.00。文字数そのものが課金単位ではありません。
- 試作60本では画面上の使用額$0.06を確認済み。ただし今回の20本の請求額は未測定です。
- 2026-10-13 01:59の残高確認は$9.82、自動チャージOFF。追加購入はしていません。
- APIの結果はMP3なので正確な請求額は返りません。実行後にOpenAI Usageで音声用キー
  `up-words-audio`を絞り込み、対象時刻のリクエスト数・使用額を確認してください。
- 20リクエストという件数上限であり、金額のハード上限ではありません。
- 公式の提供終了予定は2027-01-06。この日以降の実行は停止します。

公式資料：
- https://developers.openai.com/api/docs/models/gpt-4o-mini-tts
- https://developers.openai.com/api/docs/deprecations

## 実行

マージや通常のテストでは課金しません。

1. GitHub Actions → **Generate fixed 20 audio files** → **Run workflow**。
2. Branchをmainにする。
3. 有料の20本生成を始める場合だけ **generate** にチェックする。
4. **Run workflow** を押す。

GitHubに保存済みのOpenAIキーとR2のキーを使います。新しいキーの作成やコピーは不要です。
R2の試作60本の照合、対象20本の前回状態の点検が済んでからAPIを呼びます。
元音声・処理済み音声・進捗を1本ずつ保存します。結果不明のAPIリクエストがあれば停止し、
自動で再生成しません。

## 完了後

`nova-ash-pilot-20`をダウンロード・展開し、`listen.html`で発音・速さ・音量を確認します。
`result.json`の初回正常終了の目安：

```json
{
  "target_files": 20,
  "requested_this_run": 20,
  "reuse_check_requests": 0,
  "reuse_check_files": 20,
  "publication": "unchanged"
}
```

処理終了後にもう一度全件を検証し、追加API呼び出しゼロで再利用できることを確認します。
これは完了済み音声の再利用確認です。実通信を故意に切断する試験はしません。
途中失敗からの再開は擬似API/R2でテスト済みで、実際の失敗が起きた場合には記録を確認します。

この操作はR2へ保存するまでです。アプリの公開マニフェストは変更せず、全問生成も始めません。
20本の品質・費用を確認した後、量産と公開へ進みます。
