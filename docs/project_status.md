## 2026-06-16 study-app 音声読み上げ機能
- Web Speech API の `speechSynthesis` で現在問題の `question` を `en-US` / rate `0.85` で読み上げる。
- 問題表示時の自動読み上げはホーム画面のチェックボックスでON/OFFでき、初期値はON。設定は `localStorage` に保存。
- 問題画面に「🔊 もう一度聞く」ボタンを追加し、自動読み上げOFF時やiPhone Safariで自動再生が制限された場合でも手動再生できる。
- 日本語選択肢や正解表示は読み上げず、英単語・英語チャンク・英文和訳の英文問題だけを対象にする。

## 2026-06-16 ルートRPG本体の標準問題自動読み込み
- 起動時の読み込み優先順位を「保存済みアップロードCSV/Excel → `data/default-words.csv` → 内蔵サンプル」に整理。
- アップロードCSV/Excelは同じ端末・同じブラウザの `localStorage` に保存し、次回起動時も優先使用する。
- 端末間同期はしない方針。共通問題は `data/default-words.csv` を更新して GitHub Pages から配信する。
- データソース表示と、保存済みアップロードデータを消去して標準問題へ戻すボタンを追加。
