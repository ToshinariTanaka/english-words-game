# 英単語CSV 50行バッチ編集ツール

## 目的
教材作成者が英単語CSVを50行ずつ処理し、チャッピー向けプロンプト生成・貼り戻し・チェック・CSV書き出しを行うための管理ツールです。中学英単語・高校/大学受験・英検・TOEIC・教科書/定期テストなど複数用途で共通利用できます。生徒用英単語RPG本体とは分離されています。

## 使い方
1. `admin/wordbook-batch/index.html` をブラウザで開く。
2. 用途を選ぶ（中学英単語 / 高校・大学受験英単語 / 英検 / TOEIC / 教科書・定期テスト / カスタム）。
3. CSVを読み込む（日本語/英語ヘッダー混在可）。
4. 未処理50行または指定範囲を抽出する。
5. 選択用途に応じたプロンプトを作成してチャッピーに渡す。
6. チャッピーのCSV出力を貼り戻して反映する。
7. チェックを実行し、`OK`/`要確認` を付与する。
8. 必要なCSV形式で書き出す。

## 50行処理の流れ
- 「次の未処理50行を抽出」で、`status != completed` の行を先頭から50件取得。
- 表で確認し、プロンプトを生成。
- 返却CSVを貼り戻し、同じ `row_number` に反映。

## チャッピー用プロンプトの使い方
- 「チャッピー用プロンプトを作成」で、選択した用途（中学英単語など）に応じた指示文を含むテンプレートを生成。
- 「コピー」でクリップボードにコピーし、そのままチャッピーへ投入。
- 返却は `row_number` 付きCSVで受け取り、貼り戻し欄へ貼って反映。

## CSV列仕様
既存のマスターCSV列仕様は維持します。チャッピー貼り戻し対象は `checked_at` を除く以下の列です。

`row_number,word,meaning,gold,level,chunk1,chunk1_meaning,chunk2,chunk2_meaning,chunk3,chunk3_meaning,definition,definition_meaning,status,note`

## CSV書き出し方法
- **マスターCSV**: 管理列を含む完全版。
- **アプリ用CSV**: 補助出力。英単語RPG本体は `status` / `note` / `checked_at` などの管理列を無視できます。
