# 重要英単語CSV 50行バッチ編集ツール

## 目的
教材作成者が重要英単語CSVを50行ずつ処理し、チャッピー向けプロンプト生成・貼り戻し・チェック・CSV書き出しを行うための管理ツールです。生徒用英単語RPG本体とは分離されています。

## 使い方
1. `admin/wordbook-batch/index.html` をブラウザで開く。
2. CSVを読み込む（日本語/英語ヘッダー混在可）。
3. 未処理50行または指定範囲を抽出する。
4. プロンプトを作成してチャッピーに渡す。
5. チャッピーのCSV出力を貼り戻して反映する。
6. チェックを実行し、`OK`/`要確認` を付与する。
7. 必要なCSV形式で書き出す。

## 50行処理の流れ
- 「次の未処理50行を抽出」で、`status != OK` かつ必須4列のどれかが空欄の行を先頭から50件取得。
- 表で確認し、プロンプトを生成。
- 返却CSVを貼り戻し、同じ `row_number` に反映。

## チャッピー用プロンプトの使い方
- 「チャッピー用プロンプトを作成」でテンプレートを生成。
- 「コピー」でクリップボードにコピーし、そのままチャッピーへ投入。
- 返却は `row_number` 付きCSVで受け取り、貼り戻し欄へ貼って反映。

## CSV書き出し方法
- **アプリ用CSV**: `word,meaning,level,chunk,chunk_meaning,definition,definition_meaning`。
- **マスターCSV**: 上記に `status,note,checked_at` を含めた管理用完全版。
